## Идентификация алгоритма

Константы для поиска в бинарнике:

| Алгоритм | Константы |
|----------|-----------|
| AES | S-box `63 7c 77` / `63 7c 77 7b f2 6b 6f c5` |
| TEA/XXTEA | `0x9e3779b9` (delta) |
| MD5 | `0x67452301`, `0xefcdab89` |
| SHA1 | `0x67452301`, `0xefcdab89`, `0x98badcfe` |
| SHA256 | `0x6a09e667`, `0xbb67ae85` |
| CRC32 | `0xedb88320` (таблица) |
| Base64 | `ABCDEFGHIJKLMNOPQRSTUVWXYZabcdef...` |

## Кастомные алгоритмы
- Модифицированный AES — другая S-box таблица
  - Найти S-box в бинарнике (256 байт)
  - Заменить стандартную на найденную — тогда стандартный AES решит
- XOR с вариациями: циклический ключ, rolling key, побайтовый
  - `find_sbox_seed.py` для поиска seed
  - Анализ частот: если ключ короткий — будет повторение

## Анализ ключей
- Поиск потенциальных ключей: высокая энтропия, 16/24/32 байта
- XOR нескольких блоков известного plaintext → ключ
- Если известен алгоритм — восстановить ключ через known-plaintext
