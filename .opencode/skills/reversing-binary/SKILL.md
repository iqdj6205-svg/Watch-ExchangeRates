## Выявление типа файла

- Смотреть магические байты (первые 8-16 байт)
  - `7f 45 4c 46` — ELF
  - `4d 5a` / `5a 4d` — PE
  - `89 50 4e 47` — PNG
  - `50 4b 03 04` — ZIP/JAR/APK
  - `1f 8b 08` — GZip
  - `42 5a 68` — BZip2
  - `fd 37 7a 58 5a 00` — XZ
- Если магии нет — возможно кастомный/обфусцированный формат

## Анализ энтропии

- Высокая энтропия (7.5+ бит) — вероятно шифрование/s compression
- Средняя (6-7.5) — возможно кодирование/base64
- Низкая (< 6) — вероятно plaintext или структурированные данные
- Сравнить энтропию разных блоков — найти границы между зашифрованными и plain-секциями

## Поиск сигнатур

- Известные ключи: AES S-box (константы), RSA (большие простые), base64 table
- Поиск XOR-ключей: найти байты которые делают энтропию равномерной
- Строки: `strings` на разных энкодингах (UTF-8, UTF-16LE, ASCII)
- Константы алгоритмов: `0x9e3779b9` (TEA/XXTEA), `0x6a09e667` (SHA), CRC таблицы

## Структуры

- Искать паттерны: размеры блоков, таблицы оффсетов, заголовки
- Выровненные данные (4/8/16 байт) — структуры скорее всего aligned
- В конце файла могут быть подписи/хэши
