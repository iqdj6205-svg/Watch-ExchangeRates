## Подходы

### Прямое редактирование (hex)
- Найти паттерн в hex-дампе
- Заменить байты (учитывать длину — не сдвинуть структуры)
- Проверить контрольную сумму, если есть

### IPS патч
- Формат: `PATCh` + записи (offset, size, data) + `EOF`
- Для замены небольшого числа байт
- Не поддерживает удаление/вставку

### BSDiff
- Бинарный diff для больших изменений
- Используется в OTA-обновлениях
- `bspatch old new patch`

### Кастомный patcher
- Python-скрипт: находит паттерн, применяет изменения
- Свой инструмент когда IPS/BSDiff не подходят

## Правила безопасности
- Всегда патчить копию, не оригинал
- Проверять что есть backup оригинального файла
- После патча проверить контрольную сумму/hash
- Убедиться что не сломали выравнивание структур
- Протестировать на эмуляторе/в изолированной среде
