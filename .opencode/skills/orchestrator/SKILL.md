## Как это работает

Агент оценивает задачу по шкале сложности и выбирает стратегию.

### Уровень 1: Простая задача (быстрое действие)

**Признаки**: исправление опечатки, переименование переменной, простой ответ на вопрос, форматирование.

**Действие**: сделать сразу, без суб-агентов.

### Уровень 2: Средняя задача (требует контекста)

**Признаки**: рефакторинг функции, добавление небольшой фичи, написание тестов, исправление баги с понятной причиной.

**Действие**: собрать контекст (grep/чтение файлов) и сделать самому. Суб-агент не нужен, но нужен анализ окружения.

### Уровень 3: Сложная задача (нужен суб-агент)

**Признаки**: 
- Нужно исследовать код в нескольких модулях
- Задача затрагивает 3+ файла
- Требуется анализ архитектуры перед изменениями
- Нужно написать план перед реализацией
- Есть риск сломать смежную логику

**Действие**: 
1. Написать краткий план (3-5 шагов) в контексте
2. Создать суб-агента с чётким ТЗ (какой файл, что сделать, на что не влияем)
3. После завершения — проверить что ничего не сломалось

## Шаблон для суб-агента

Когда делегируешь суб-агенту, передавай ему:
1. Какой файл/функцию менять
2. Что конкретно сделать (с примерами)
3. Что НЕ трогать
4. Какие тесты запустить для проверки
