## Методы

### Побайтовый diff
```bash
cmp -l v1.bin v2.bin | head -50  # отличия в байтах
xxd v1.bin | diff - v2.hex       # наглядный diff
```

### Dump сопоставление
- Если структура блоков изменилась — сначала выровнять по границам
- Сравнивать не весь файл, а секции: .text, .data, .rodata
- Для прошивок: сравнивать каждый раздел отдельно

### Semantic diff
- Дизассемблировать обе версии → сравнить функции
- Новые функции: только во v2
- Изменённые: разный код, но те же аргументы
- Удалённые: только во v1
- Ghidra/IDA: экспорт .gzf/.idb, бинарное сравнение
