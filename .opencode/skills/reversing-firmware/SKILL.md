## Процесс

1. Определить формат прошивки:
   - CHIP/TRX — заголовок с оффсетами разделов
   - U-Boot — uImage + FIT
   - SquashFS/JFFS2 — файловая система
   - Vendor-specific — кастомный бандл

2. Извлечь образ:
   - `binwalk` — рекурсивно ищет вложенные архивы
   - manual split — если кастомный контейнер
   - entropy analysis — найти границы между блоками

3. Если зашифровано:
   - Определить алгоритм по константам (AES, DES, XOR, TEA)
   - Поиск ключа в той же прошивке (часто рядом)
   - Обратная разработка алгоритма расшифровки

4. Если сжато:
   - LZMA, LZSS, Deflate, RLE — определить по сигнатуре
   - Распаковать, проверить энтропию результата

## DJI специфика
- FW блоки с заголовками: off, type, size
- waes — кастомное шифрование AES-based
- sbox — замена S-Box для кастомного AES
- Многослойная упаковка (compress → encrypt → compress → ...)
- Искать OTA заголовки и версии прошивки
