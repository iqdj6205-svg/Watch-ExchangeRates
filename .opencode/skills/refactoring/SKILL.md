---
name: refactoring
description: Пошаговый рефакторинг с сохранением работоспособности.
---

## Процесс

1. Прочитать модуль полностью, понять что он делает
2. Написать тесты на текущее поведение (characterization tests)
3. Составить план рефакторинга:
   - Каждый шаг — одно логическое изменение
   - Шаги маленькие (можно откатить)
4. Выполнять шаги по одному:
   - После каждого шага — тесты должны проходить
   - Иначе откатить и переделать
5. В конце — проверить что тесты проходят, удалить characterization тесты

## Запрещено
- Менять API/public-контракты без отдельного обсуждения
- Рефакторить и добавлять фичи в одном коммите
- Оптимизировать без замеров производительности
