## Что проверять

### Инъекции
- SQL, NoSQL, Command, LDAP — везде где есть интерполяция строк
- Используются параметризованные запросы

### Аутентификация и авторизация
- Проверка прав на каждом эндпоинте
- Нет хардкода паролей/токенов — использовать `token_env` или переменные окружения
- JWT проверяется (не только декодируется)

### Data leakage
- Логи не содержат PII (email, phone, passport)
- Ошибки не показывают stack trace пользователю
- Ответы API не возвращают лишних полей

### Зависимости
- Нет известных уязвимостей (проверить через `npm audit`, `pip audit` и т.д.)
- Версии не зафиксированы с уязвимостями
